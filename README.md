# Superstore Sales Analysis & Excel Dashboard

## Project Overview

This project analyzes retail sales data using Python, Pandas, NumPy and Matplotlib. The goal is to clean the dataset, calculate important business KPIs, identify sales and profit patterns, and present the results through an Excel dashboard.

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Microsoft Excel
* Google Colab

## Dataset

The project uses the Sample Superstore dataset containing retail sales information such as:

* Category
* Sub-Category
* Region
* State
* Segment
* Sales
* Quantity
* Discount
* Profit

## Data Analysis

The analysis includes:

* Missing-value analysis
* Duplicate detection
* Data type validation
* Category-wise sales analysis
* Sub-category analysis
* Regional sales analysis
* State-level analysis
* Customer segment analysis
* Discount vs. profit analysis
* Profitability analysis

## Key KPIs

The project calculates:

* Total Sales
* Total Profit
* Total Quantity Sold
* Total Transactions
* Average Sales
* Profit Margin

## Dashboard

An Excel dashboard was created to present the major KPIs and analysis results in an easy-to-understand format.

## How to Run

1. Open the notebook in Google Colab.
2. Upload `SampleSuperstore.csv`.
3. Run the notebook cells sequentially.
4. The analysis and visualizations will be generated.
5. The processed analysis can be exported to Excel.
